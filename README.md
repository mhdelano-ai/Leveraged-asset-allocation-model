# assetpred

Can machine learning predict the excess return of an asset class over T-bills,
one, three and twelve months ahead, better than that asset's own historical
mean? This repository is a test of that question for eleven asset classes, with
the forecast taken as a full predictive distribution and the joint covariance
forecast alongside it. It is research: no portfolio decision is attached.

The dashboard is the place to read the results: `results/dashboard.html`,
generated by `python -m assetpred.dashboard.build`.

## What was found

Models were developed on forecasts whose outcomes were known by the end of 2014.
The model lists, the test families and the scoring rules were then frozen
(commit `7577b13`), and forecasts made from January 2015 to October 2026 were
scored once. These are the holdout results.

| Question | 1 month | 3 months | 12 months |
|---|---|---|---|
| Expected return: best out-of-sample R² of six models against the historical mean | +0.10% | +0.41% | +2.21% |
| Smallest R² this sample could detect | 1.9% | 5.5% | 20.0% |
| Test that any of the six beats the historical mean (p) | 0.55 | 0.35 | 0.27 |
| Distribution: best CRPS gain of five models over a volatility-tracking baseline | +1.03% | +1.22% | +1.14% |
| Test that any of the five beats that baseline (p) | 0.10 | 0.14 | 0.21 |
| Covariance: log-score gain of the primary model over static shrinkage, nats per asset | +0.086 | +0.097 | +0.074 |
| Adjusted p-value of that gain (q) | 0.003 | <0.001 | <0.001 |

- **Expected returns are not predictable here.** No model beats the historical
  mean at any horizon. The two hints from development reversed in the holdout: a
  price-only boosting model went from +0.57% to -0.61% at one month, and the
  ensemble from +1.50% to -1.06% at twelve.
- **The distribution forecasts are better than the baseline in every holdout
  comparison, but not significantly.** A small linear volatility model does the
  work; boosted trees on top of it scored lower at every horizon.
- **Covariance forecasts that move with the data beat static shrinkage.** This
  is the one result that holds in the holdout. A plain exponentially weighted
  covariance does about as well as the more elaborate models.
- **The forecasts were worth nothing in a portfolio.** After costs, 16 of 18
  model-and-rule combinations did worse at one month than the same rule run on
  historical means, six of them significantly. During development the same
  comparison had favoured the models.

## Limits worth knowing before trusting any number

- Gold returns start in December 2004; no free month-end price history could be
  downloaded. Supplying `data/raw/lbma/gold_pm.json` and rebuilding extends it
  to 1968.
- Investment-grade credit is a long-duration Vanguard fund, not a broad index,
  and the high-yield series is a fund NAV whose returns are smoothed.
- Twelve-month results rest on about 11 independent observations in the holdout,
  and two of the tests reject a true null 7.5-10.5% of the time at that horizon.
- There is no high-yield spread, REIT dividend yield or emerging-market
  valuation measure among the predictors.
- 75 configurations were tried during development (`results/dev/trials_*.csv`).
  The adjusted tests account for the frozen models, not for all 75.

## Running it

```
pip install -e .[dev]
python -m assetpred.pipeline --dev     # development period only
python -m assetpred.pipeline           # the full run, holdout included
pytest                                 # about 13 minutes; network tests are deselected
```

The pipeline reads the committed panels in `data/processed/`. To rebuild them
from source: `python -m assetpred.data.assets`, `python -m
assetpred.data.predictors` (about 20 minutes from an empty cache), then `python
-m assetpred.features.build`.

The holdout has been scored. Changing a model and rerunning the full pipeline
would turn those years into a tuning sample; new ideas need new data, or a new
holdout declared in `config.py` before they are tried.

## Layout

- `src/assetpred/config.py` - universe, horizons, holdout dates, frozen model lists
- `src/assetpred/schema.py` - the data contract between stages
- `src/assetpred/data/` - asset returns and point-in-time predictors
- `src/assetpred/features/` - the feature panel
- `src/assetpred/models/` - baselines, mean models, distribution models
- `src/assetpred/covariance/` - covariance forecasting and its evaluation
- `src/assetpred/evaluation/` - walk-forward engine, scoring, inference, strategy test
- `src/assetpred/dashboard/` - the dashboard generator
- `results/` - the holdout run; `results/dev/trials_*.csv` - what was tried
